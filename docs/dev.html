Quickstart — get a wallet on ACiD in 60 seconds

  1. Open MetaMask (or any EIP-1193 wallet)
  2. Click Add network and use the values above, OR open the demo dApp and click "Add ACiD to wallet" for one-click setup
  3. Go to faucet-acid.livingagentic.me, paste your address, claim 0.001 ACiD ETH (no login, 1 claim per address per 24h)
  4. Open the demo dApp, connect wallet, send a 0.0001 ETH burn transaction, watch it confirm on the explorer

Deploy a smart contract

Standard EVM. Anything Solidity-compatible deploys to ACiD with no modifications.

With Foundry (recommended)

# Install Foundry once
curl -L https://foundry.paradigm.xyz | bash
foundryup

# Add ACiD to your foundry.toml
[rpc_endpoints]
acid = "https://rpc-acid.livingagentic.me"

[etherscan]
acid = { key = "ANY_NON_EMPTY", url = "https://explorer-acid.livingagentic.me/api/", chain = 1714 }

# Deploy any contract
forge create src/MyContract.sol:MyContract \
  --rpc-url acid \
  --private-key $PRIVATE_KEY \
  --legacy

# Verify on the explorer
forge verify-contract <ADDRESS> src/MyContract.sol:MyContract \
  --rpc-url acid \
  --verifier blockscout \
  --verifier-url https://explorer-acid.livingagentic.me/api/

With Hardhat

// hardhat.config.js
module.exports = {
  solidity: "0.8.24",
  networks: {
    acid: {
      url: "https://rpc-acid.livingagentic.me",
      chainId: 1714,
      accounts: [process.env.PRIVATE_KEY],
    }
  },
  etherscan: {
    apiKey: { acid: "ANY_NON_EMPTY" },
    customChains: [{
      network: "acid",
      chainId: 1714,
      urls: {
        apiURL: "https://explorer-acid.livingagentic.me/api/",
        browserURL: "https://explorer-acid.livingagentic.me",
      }
    }]
  }
};
    
npx hardhat run scripts/deploy.js --network acid
npx hardhat verify --network acid <ADDRESS> <CONSTRUCTOR_ARGS>

With Remix (browser, no install)

  1. Open remix.ethereum.org
  2. Write or paste your contract
  3. Compile
  4. Deploy tab → Environment: Injected Provider — MetaMask
  5. Make sure MetaMask is on ACiD (Chain ID 1714)
  6. Click Deploy. Confirm in wallet. Done.

RPC methods supported

All standard eth_*, net_*, web3_* JSON-RPC methods. OP Stack adds optimism_* namespace for L2-specific queries (output roots, withdrawal proofs, etc.). Hit the RPC with any standard Ethereum library — viem, ethers, web3.js, wagmi, all work as-is.

# Smoke test
curl -X POST https://rpc-acid.livingagentic.me \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'

# Returns {"jsonrpc":"2.0","id":1,"result":"0x...."}

Rate limits + caveats

  • 10 requests per second per source IP sustained, enforced at the Cloudflare edge. Plenty for any dApp or single user. Spike traffic from one IP gets rate-limited, not banned
  • POST only for JSON-RPC (standard). GET to the RPC root returns a 200 placeholder, not method handling
  • No archive-mode trace methods: debug_traceTransaction and similar may not return for blocks older than a few days. Recent blocks work
  • Testnet: chain state may reset if we hit major upgrade points. We try to avoid this but it can happen. Don't put anything irreplaceable on here
